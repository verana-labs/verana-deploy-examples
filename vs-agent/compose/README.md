# VS Agent on one host with Docker Compose

The files of the "[Deploy on one VM with Docker Compose](https://docs.verana.io/docs/build/verifiable-services/docker-compose)" guide: the Compose stack (agent, PostgreSQL, Redis, Caddy), the Caddyfile, the environment template. Copy `.env.example` to `.env`, fill it in, `docker compose up -d`.

Status: verified against the v4 testnet after the 13 October 2026 upgrade (date to be set).
